# The SwiftUI emitter's vocabulary: every SDK API the generated package can call, one dotted
# symbol-graph path per line, as `scripts/swiftui-api show` prints it.
#
#   scripts/swiftui-api audit Tests/WoodcaseTests/Fixtures/swiftui-vocabulary.txt --floor ios=26,macos=26
#   scripts/swiftui-api audit Tests/WoodcaseTests/Fixtures/swiftui-vocabulary.txt --floor ios=18,macos=15
#
# Both must exit 0. `SwiftUIVocabularyTests` fails when the emitted code (the support
# templates, every SwiftUI golden, and the code fragments in the emitter's own string
# literals) calls an API this list does not name; see the SwiftUIChurn DocC article.
#
# Annotations after a path:
#   @available ios=26,macos=26   reached only inside `#available(iOS 26, macOS 26, *)` in the
#                                support file: the audit holds it to that gate, not the floor
#   @only macos                  reached only on these platforms (`#if os(macOS)`,
#                                `#if canImport(UIKit)`): the others are not checked
#
# Adding an API is one line in the section it belongs to. Overloads share a path, so a path
# covers every overload of that name and label list.
