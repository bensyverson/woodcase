# Concepts: agent 4

## Glow Keynote

The idea is the product-launch keynote: one statement per slide, huge, centered, with one piece of proof under it. Every slide obeys that rhythm, so the deck reads like a stage show without a stage. The ground is near-black (#0B0B0F) with a single radial gradient bloom, a violet-to-teal wash at 18% opacity that sits low and off-center and drifts one position per slide so the light seems to move as you page. Type is Inter Tight at 132 pt, weight 600, tracking −3%, white at 96%, with a secondary line in Inter 400 at 40 pt, 55% white; code is JetBrains Mono 28 pt in a rounded 24 px card with a 1 px 10%-white stroke, a background blur and an outer shadow. The gap is "Agents write code. They can't see design." over an empty, dimmed card with a broken outline. The loop is three words, Command · View · Iterate, each over its own small card: a `set` line, the real `tree` excerpt, and a `shot` thumbnail drawn from the banking fixture. JavaScript is a single `woodcase js` card with the line that throws highlighted in amber, headed "Measure, then commit." The outlets are a row of five glassy tiles with Lucide icons: CGContext, PNG, PDF, React, SwiftUI. The reveal breaks the pattern: the glow goes out, the ground turns flat black, and the activity log fills the slide edge to edge in dim mono with the headline "This deck was built by an agent" set over it. Before reading a word, the reader sees a dark, glowing, expensive-looking Apple-style deck, and recognizes it at once.

## Terminal Transcript

The idea is that the deck is a single terminal session: every slide is the next screen of one scrolling shell, the prompt carries the story, and the prose is whatever the tool prints back. There are no headlines, only commands and their output, plus one comment line (`# …`) per slide in a muted color that does the talking. The ground is a warm charcoal (#1C1B19) with no window chrome and no traffic-light dots, just the terminal content set in a 1680-wide column with an 80-column feel. The palette is the terminal's own: off-white text, a green prompt `$`, amber for warnings, red for the one exit code. Type is IBM Plex Mono throughout at 30 pt with 1.45 leading, and the comment lines are Plex Mono Italic. The gap is `$ claude "make the header feel calmer"`, answered by a comment: `# it edited the CSS. it never saw the header.` The loop is three commands stacked on one slide: `tree` with the real banking output, `set header kind.padding=…` answered by a new `rev`, then `shot` answered by a small inline render of the header, the only picture in the transcript. JavaScript is a `woodcase js` heredoc where the script measures, throws, and the shell prints `nothing written`. Built with its users is a deliberate typo answered by an error that teaches, with near misses listed. The outlets are `generate react`, `generate swiftui` and `render --format pdf`, each answered by a one-line file listing. The reveal is `$ woodcase activity deck.pen`, whose output is this deck's own history. The last slide breaks the pattern by holding nothing but the cursor after the install command, blinking as a solid block. Before reading, the reader sees a dark screen of monospaced text and knows it is for them.

## Swiss Grid

The idea is an International Typographic Style poster series: a strict twelve-column grid on 1920×1080 with 80 px margins, flush-left ragged-right type, and one oversized numeral per slide that anchors the composition and counts the beats. The grid is not decoration; every block snaps to it, and the numeral's position walks one column to the right each slide, so the deck has a visible spine. The ground is paper white (#F4F2EE), the text near-black, and a single signal red (#E4312B) used only for the numeral and one word per slide. Type is Inter Display for headlines at 96 pt, weight 700, tight leading 0.95, with Inter 400 at 28 pt for body; code is Space Mono 24 pt, black on a pale gray field aligned to the grid. The gap is a red "1" and two columns: "Agents write the code" left, "and cannot see the design" right, with a thin rule between that stops short. The loop is three equal columns headed Command, View, Iterate, each holding one real snippet, the three joined by a hairline arrow that returns under the grid. JavaScript is a single tall column of script, the throwing line struck through in red. The outlets are a typographic list of five destinations, set large, each with a ten-word gloss. The reveal breaks the grid: the activity log is set as a dense small-type column that spills over every column line, the only slide where the grid is overrun. Before reading, the reader sees a clean white page, a huge red number and black blocks in exact alignment.

## Call and Response

The idea is that every slide is split down the middle: on the left what an agent sends, on the right what it gets back. The deck becomes a conversation between an agent and the tool, and the split carries every beat rather than being a layout used for some. The left half is a dark graphite field (#16181C) holding the command in monospace; the right half is a light field (#F6F6F3) holding the answer, whether text, a render or a file listing. One accent, electric blue (#2F6BFF), marks the revision token, which travels from the right-hand answer back into the next slide's left-hand command. Type is Geist Mono at 32 pt for commands and Geist at 36 pt for the single sentence at the foot of each half. The gap is a left half holding a vague prompt and a right half that is empty except for the words "no feedback." The loop is the `tree` command left and the real `tree` table right, then on its own slide `set` left and the new rev plus a `shot` of the changed header right. JavaScript is a longer script left and, right, the two possible answers stacked: committed, or thrown and nothing written. The outlets are the one slide where the right half subdivides into five cells, a PNG, a PDF page, a React file, a SwiftUI file and a CGContext drawn view, all from the same command family. The reveal breaks the pattern by removing the split: the whole slide turns to the right-hand light field, and it holds this deck's own activity log as the answer to a question nobody on the left asked. Before reading, the reader sees a hard dark/light halving that repeats page after page.

## Loop Spine

The idea is one diagram that never leaves: a ring of three nodes, Command, View, Iterate, sits in the same place on every slide, drawn as a 360 px circle with three dots on the left third of the frame, and each slide lights the part of the loop it is about while the right two thirds explain. The ring is the navigation, the thesis and the slide number at once. The ground is deep ink blue (#0E1A2B), the ring a 3 px stroke in 30% white, the active arc drawn with an angular gradient from teal (#3EE6C1) to white that sweeps only the segment in play, with a soft outer glow on the lit node. Type is Space Grotesk at 84 pt, weight 500, for the one headline, and Space Mono 26 pt for everything the tool prints. The gap is the ring broken: the arc between View and Iterate is missing, a physical gap in the circle, with "Agents can't see what they changed." The loop lights each node in turn across one slide, with the real `tree`, `set` and `shot` lines placed next to their nodes. JavaScript draws a second, small ring inside the first, spinning the whole loop in one transaction, with the script beside it. Built with its users makes the ring thick and shows attributed writes as small ticks around its circumference. The outlets break the ring's containment: five spokes run from its center out to the right edge, each ending in CGContext, PNG, PDF, React or SwiftUI. The reveal traces the ring once for every entry in the deck's activity log, so the circle becomes a dense spiral of hairlines, with the log beside it. Before reading, the reader sees the same glowing circle on every page, partly lit.

## Agent's Eye

The idea is that the deck is shown the way an agent perceives design: as text first. Nearly every slide contains no drawing at all, only text laid out as `tree` lays it out, and pictures appear only where `shot` would be called, as the last mile. The discipline runs through every slide: an image must be earned the way a screenshot is. The ground is a pale gray-green (#E9ECE6), unlit and flat, the ink a dark olive-black (#1D211C), with one muted signal orange (#D9642B) reserved for ids and revs. Type is JetBrains Mono for everything, at a single size of 30 pt on a strict character grid, with hierarchy made only by weight and by capitals; there is no second typeface. The gap is a slide holding only a human prompt and an agent's reply that admits it cannot see, set as two blocks of text. The loop is the real banking `tree` output set large, filling the page, with three annotations in orange; the `shot` beat is the first image in the deck, a single rendered header sitting in the grid exactly where its row would be. JavaScript is a script and a two-line transcript, no chrome. The outlets are a list of five lines, each a verb and a destination. The reveal is the only slide with color beyond orange: this deck's own tree, with its slides as rows, each row paired with a thumbnail of the slide it describes. Before reading, the reader sees an almost blank gray page of evenly set monospace, and senses that text is the medium.

## Rev Ledger

The idea is that the deck is a ledger of its own revisions: each slide carries, as its folio, the real revision token and the command that last changed it, so the page numbers are hashes and the footer is history. The story advances by revisions rather than by page count, and every slide is visibly a step in the loop that made it. The ground is a bone ledger paper (#F3EEE3) ruled with faint horizontal lines every 40 px in a pale blue-gray, with a double red rule down the left margin as an accounting book has. Ink is a dark sepia-black; the accent is ledger red (#B23A2E) for revs. Type is IBM Plex Serif at 76 pt for the one statement per slide, IBM Plex Mono 22 pt for folios and figures, set on the ruled baselines. The gap is an unbalanced entry: a column of "code written" ticks, a column of "design seen" left blank. The loop is three ledger lines, command, the new rev and a small `shot` pasted in like a receipt. JavaScript is an entry that is struck out in red because the script threw, with "nothing written" as the balance. Built with its users is a column of `--as` attributions, agent names in the margin. The outlets are five columns of a ledger spread, one per destination. The reveal breaks the pattern by turning the ledger over: the slide is the activity log itself, every line of it, with the rev of this very page circled in red at the bottom. Before reading, the reader sees ruled cream paper, a red margin and small hashes in the corners.

## Wood Type Case

The idea comes from the name: a woodcase is a printer's type case, a shallow drawer of compartments that each hold one sort. Every slide is a type case seen from above, a grid of compartments of differing sizes, and the content of each beat sits in its compartments like sorts; the layout engine's flex boxes are literally the drawer's dividers. The ground is warm maple (a linear gradient from #D9B98A to #C9A571, with a subtle mesh gradient for grain rather than any photograph), the dividers drawn as 10 px strokes in a darker walnut with an inner shadow so each cell reads as recessed. Ink is black and a letterpress vermilion (#D2412A). Type is Alfa Slab One for the few large display words, set like wood type at 180 pt, and Courier Prime 26 pt for the commands, as if proofed on a galley. The gap is an empty drawer with one full compartment, "code," and every other cell empty. The loop is three compartments in a row holding `tree`, `set` and `shot`, the shot compartment holding a small render. JavaScript locks a chase: a thick frame around a group of compartments, "one transaction," nothing leaves until it is locked. The outlets are the drawer tipped out into five stacks. The reveal breaks the pattern by leaving the drawer: a plain white proof sheet, the activity log pulled as a galley proof, with crop marks at its corners. Before reading, the reader sees warm wood, dark dividers and a few enormous slab letters.

## Fidelity Ramp

The idea is that the deck iterates in front of the reader: slide one is a gray wireframe, the boxes and labels an agent reads in `tree`, and each slide gains one layer of fidelity (type, then color, then light, then effects) until the reveal is fully finished. The whole deck is the loop, command, view, iterate, played at the scale of the deck itself, and every slide's style is literally one step further than the last. The ground begins as white with 1 px gray rects labeled by name and `w×h`, and ends as a deep, fully rendered composition: a mesh gradient in indigo, coral and sand, soft inner shadows, a background blur behind glass cards. Type begins as a system mono placeholder, arrives as Instrument Sans at slide three, and gains Instrument Serif italic for one emphasized word per slide from slide five on. The gap is pure wireframe: two boxes, "code" solid and "design" dashed with no fill. The loop is three wireframe cards acquiring real type as they go left to right. JavaScript is the slide where color arrives, and the script is the thing that applied it. The outlets are the slide where effects arrive, five cards each with a different treatment, rendering the same card into five destinations. The reveal breaks the ramp by stepping back: all slides shown small, in order, as a strip, with the activity log beneath each one naming the commands between it and the next. Before reading, the reader sees an unfinished page, and in paging, sees it finish.

## Self-Annotated

The idea is that every slide shows its own `tree`: each element on the page carries a small printed tag of its name, rect and id, as the tool reports it, so the reader sees the design and the agent's reading of it at once. The annotation is not added to some slides; it is the house style, and the reader learns to read `tree` without being taught it. The ground is a very dark green-gray (#101412) with one element at a time brought to full white; everything else, and every tag, sits at 40% in a pale mint (#A8E6CF), hairline leader lines in 1 px connecting each tag to the box it measures, and a faint dashed outline around every frame's rect. Type is Hanken Grotesk at 88 pt for the statement, Martian Mono 16 pt for the tags, set at the top-left corner of each box exactly where the rect's origin is. The gap is a slide whose headline is tagged but whose visual is untagged: a render with no ids, unreadable to the agent. The loop places the real banking header on the page, tagged with the real `tree` output line by line. JavaScript shows a tag changing: one element's rect drawn twice, before and after, the script's measurement between them. The outlets tag the same box with five destinations. The reveal breaks the pattern by stripping every tag and showing only the activity log, so the reader realizes the tags were real all along, and the log is how they came to be. Before reading, the reader sees a dark page threaded with small mint labels and hairlines, like an instrument.
