# Concepts: agent 5

## Statement

The deck is nine sentences, one per slide, and nothing else competes with them: the idea is that a skeptical developer trusts a claim set plainly more than a claim decorated, so each slide carries exactly one assertion at display size and one small piece of evidence under it. The ground is warm off-white (#F4F1EA) with near-black ink (#161514) and a single accent, a saturated vermilion (#E0412B), spent only on the word that carries each slide's turn; the light is flat, no shadows, no gradients. Type is Inter Tight at 132 pt, weight 600, tracking −2%, set flush left on a 12-column grid with a 160 px left margin, and JetBrains Mono at 28 pt for the evidence line. The gap is "Agents write the code. They can't see the design." with "see" in vermilion; the loop is "Command. View. Iterate." with the five `tree` rows from `banking.pen` set in mono beneath; JavaScript is "Measure after you write. Throw instead of commit." over a four-line `woodcase js` excerpt; the outlets are "One engine. Every outlet." over a single mono line `CGContext · PNG · PDF · React · SwiftUI`; the reveal breaks the pattern by inverting to ink ground and dropping the headline to 48 pt so the activity log that built the deck fills the page in mono. Before reading, the reader sees a large dark sentence on paper and one red word, the same shape on every page, which reads as confidence.

## Session

Every slide is a terminal window, because the reader lives in one and the product is used from one: the deck is a single long session split into nine screens, and the narrative is the scrollback. The ground is a deep blue-black (#0D1117) at full bleed with no window chrome, no traffic lights, no fake title bar; text is a soft gray (#C9D1D9), prompts in green (#56D364), the revision token in amber (#E3B341), errors in red, and the only light is the cursor, a solid block drawn as a rectangle at the end of the last line on each page. One typeface, IBM Plex Mono, at a single size (34 pt, line height 1.35) across the whole deck so it reads as a real 80-column-ish screen, with narrative lines set as shell comments (`# agents can write the code…`). The gap is a comment, then `$ open design.png` answered by `error: an agent cannot look at this` in red; the loop is literally `tree`, `set … --rev 7cf8d84e7b6b9b23`, `shot` with their real output; JavaScript is a heredoc into `woodcase js` ending in `throw`, followed by `nothing written (exit 1)`; the outlets are one `generate swiftui`, one `generate react`, one `render --format pdf` with their file listings; the reveal is `woodcase activity intro.pen` with the deck's own log; install is a lone prompt with the brew line and the cursor. The pattern breaks on the outlets slide, where the shot's output is not text but the rendered banking header drawn in full color right in the scrollback, the one picture in the deck. Before reading, the reader sees a dark screen and green prompts and knows exactly who this was made for.

## Two readers

Every slide is split down the middle at x = 960: left is what an agent reads, right is what a human sees, and the deck's argument is that Woodcase makes the two halves describe the same thing. The left half is ink (#111) with mono text in pale gray; the right half is a pale neutral (#EDEDED) holding pixels; the seam is a 2 px vermilion rule that runs through all nine pages at the same x, and the light is a soft outer shadow under whatever sits on the right, as if on a desk. Type is Space Mono 26 pt on the left, Instrument Sans 64/72 pt for the one headline, which always sits on the right above the picture. The gap has an empty left half, only a blinking-cursor rectangle, against a finished mobile screen on the right: the agent has nothing to read. The loop fills the left with the `tree` rows and draws the same five rects on the right as outlines around the rendered header, row-to-rect in matched positions; JavaScript puts the script on the left and on the right the frame before and after, the after measured with a dimension line; the outlets put one Swift package tree on the left and the same component rendered as SwiftUI, React and PDF thumbnails on the right. The reveal breaks the split: the seam slides to x = 1600 and the left grows to hold the activity log, with the deck's own page thumbnail squeezed on the right. Before reading, the reader sees dark/light halves and understands there are two audiences.

## Exploded pipeline

The deck is one diagram, the pipeline, built up a stage per slide as an exploded stack of planes: parse, resolve, expand, layout, render, drawn as parallelogram polygons receding in isometric depth, so the reader always knows where in the engine they are. The ground is a cool pale gray (#E9ECEF) with a blueprint-quiet dot grid of 2 px dots at 40 px; planes are translucent white at 70% opacity with a 1 px slate stroke and a soft inner shadow, and each stage's plane lights in a signal teal (#0FA3B1) when it is the subject. Type is Manrope, 700 for 72 pt headlines, 400 for 24 pt labels set along the plane edges, with Fira Code for any literal. The gap shows the stack with only the bottom plane (render) filled and a dashed empty channel running up from it back to an agent glyph: no way back. The loop turns that channel into a closed arc of three arrows labeled `tree`, `set`, `shot`, touching the layout and render planes; JavaScript places a bracket around the whole stack labeled "one transaction", with a small red stop mark where a throw would abort; the outlets slide fans five thin arrows off the render plane to CGContext, PNG, PDF, React and SwiftUI labels. The reveal breaks the isometric view: it flattens to a straight-on page showing the stack as a single plane, the deck file itself, with its log beside it. Before reading, the reader sees a technical drawing of layers and expects rigor.

## Debug overlay

Every slide is drawn with its own layout debugger switched on: each element carries a hairline bounding box and a tiny label with its node name, rect and five-character id, exactly the columns `tree` prints, so the reader is shown on every page what an agent reads without being told. The ground is white; content is in black; the overlay is a thin magenta (#FF2D9B) at 1 px with labels in 12 pt, the color of layout debuggers everywhere, and padding and gap regions are hatched in 10%-opacity magenta; there is no light, no shadow. Type is Geist at 88 pt 600 for headlines and Geist Mono at 12 pt for the overlay labels, which are real values read back with `tree` after layout. The gap slide shows a single sentence whose bounding box is labeled `rect ?` and `id ?`, the only unknowns in the deck; the loop slide shows the five `tree` rows with each row's box connected by a magenta leader to its rendered rect in a banking-header rendering; JavaScript shows a headline whose overlay records two widths, the one before and after the script measured and shrank it; the outlets slide shows one card with its overlay and three code excerpts whose boxes are labeled with their file paths. The reveal breaks the pattern by turning the overlay off for the first time: a clean page with only the activity log and the line "every box you saw was read, not drawn by hand." Before reading, the reader sees pink hairlines around everything and senses the scaffolding.

## Woodcut

Take the name literally: the deck is printed from relief blocks, flat two-ink impressions with the edges and grain of cut wood, because the product is a hard, carved, durable tool and not a glossy SaaS app. The ground is an uncoated cream stock (#EFE6D2) with a faint paper tooth made of a mesh gradient; ink is a dense carbon black (#1B1A17) and a single second ink, a cadmium orange (#E8712A), overprinted with multiply blend so where they cross they darken; no gradients in the forms, no shadows. Type is Alfa Slab One at 160 pt for one or two words per slide, cut tight, and Courier Prime 26 pt for the small literal lines, as if typed on a slip tucked under the block. The gap is a single large carved agent glyph (an eye drawn as a pointed-oval path) with its pupil cut away, the word "blind" beside it; the loop is three carved blocks, `tree` `set` `shot`, arranged in a ring with carved arrows; JavaScript is a block with a cut-through seam and the orange ink stopped at the seam, "nothing prints unless the whole block does"; the outlets are one block pulled five times across the page in shifting orange and black registration, each pull labeled with an outlet; the reveal breaks the pattern by abandoning the carving entirely for a typewritten activity log on plain paper, the printer's ledger. Grain is drawn with long, slightly wavering paths in 8%-opacity black. Before reading, the reader sees a printed, handmade object from a place they did not expect, and wants to know why.

## Main titles

The original use case was agentic title design inside a video editor, so the deck is a film's title sequence: every slide is a title card inside 2.39:1 letterbox bars, and the reveal is the end credits. The ground is black; the picture area between the bars is a very deep warm charcoal (#141210) lit by one large radial gradient from off-frame upper left, like a spotlight on a stage cloth, and type is a warm white (#F3EDE2) with an outer glow of 2% at 30 px; a timecode sits in the lower bar in amber at 14 pt. Typefaces are Cormorant Garamond Light at 110 pt, generously tracked (+6%), centered, and DM Mono at 16 pt for the timecode and credits roles. The gap is a card that reads "A picture no agent could see", title-card style, with nothing else; the loop is three consecutive cards merged onto one page as a contact strip, "Command / View / Iterate", each with a small real `tree` line as its subtitle; JavaScript is a card with "one take" as the title and a script as the credit; the outlets are a distribution card listing "Presented in CGContext · PNG · PDF · React · SwiftUI" as if they were formats and theaters. The reveal breaks the letterbox: the bars open to full bleed and the activity log rolls as end credits, role on the left (`--as` identity), verb and path on the right, two columns centered on a gutter, exactly as film credits are set. Install is the post-credits card. Before reading, the reader sees black bars and a single line of light and assumes they are about to watch something.

## Press proof

The deck is a printer's proof of itself, a machine-made artifact checked before it ships: every page carries crop marks, registration targets, a color bar and a slug line, and the slug is real, printing the file name, revision token and node id of the slide it sits on. The ground outside the trim is a neutral proof gray (#D6D6D3) and the trimmed page is white; the slide content sits inside the trim with generous margins; the color bar at bottom left is built from the document's own variables so it changes if the theme changes, and the registration targets are black hairline circles and crosshairs; no shadows except a hair of outer shadow on the trimmed sheet. Type is Newsreader for headlines at 96 pt, regular, sentence case, and Martian Mono at 11 pt for slugs and 22 pt for literals. The gap, loop, JavaScript and outlets each sit inside the trim as a single editorial spread (headline, one short paragraph, one literal: the `tree` rows, a `js` excerpt, a list of five outlets drawn as five small swatches in the margin), and a proofreader's mark in red (#D2232A) is circled on each page, pointing at the one word the slide turns on. The reveal breaks the pattern by turning the slug line into the content: the trim is empty, the slug grows to fill the page, and it becomes the activity log. Before reading, the reader sees crop marks and color bars and understands the pages are output, not slides.

## One canvas

The nine pages are not nine slides but nine crops of a single enormous artboard, and one continuous line, the loop, runs across all of them, exiting the right edge of one page and entering the left edge of the next at the same height, so the PDF reads as one strip and the reader feels a single continuous surface an agent works across. The ground is a very pale warm gray (#F2F0EC) with no page furniture; the line is a 6 px stroke in deep ultramarine (#2433D6) with round caps, and where it passes content it becomes a boundary, curving around text, turning into an underline, closing into a rect; there is no light but the line. Type is Syne at 800 for headlines, 96 pt, sitting in the curves the line makes, and Azeret Mono at 24 pt for literals. The gap is where the line starts, a stub at the left edge that stops short of a design frame with a small break; the loop is where the line makes its first full circle through three labeled points `tree`, `set`, `shot`; JavaScript is where the line becomes a single closed transaction shape, a rounded rectangle containing the script, with a spur that would have exited but is cut; the outlets are where the line forks into five strands each ending at an outlet label. The reveal breaks the pattern by zooming out: the whole artboard in one page, the nine crops outlined, and the log running along the line's length as its caption. Before reading, the reader sees a blue line leaving the page and turns the page to follow it.

## Onion skin

Every slide shows its own history: the current state in full ink and its earlier revisions ghosted behind it at stepped opacities, 40%, 20%, 10%, offset by the few pixels each edit moved them, like an animator's onion skin, so iteration is not described but seen on every page. The ground is a cool near-white (#F6F7F9), the current revision is ink (#101216), the ghosts are the same ink at lower opacity with a one-step background blur on the oldest, and the only color is a lime marker (#B8E62E) under the revision token that labels the current layer. Type is Hanken Grotesk 600 at 100 pt for headlines, and Commit Mono 20 pt for tokens and literals; every headline's ghosts are its real earlier drafts, taken from the log. The gap shows a sentence with no ghosts at all, frozen, the one page where nothing iterates; the loop shows a banking header whose ghosts step toward the final layout in three moves, each labeled `set` with its token; JavaScript shows a heading whose ghost is wider than the trim and is struck through, the draft the script measured and threw away, with the current one fitting; the outlets show one card whose ghosts are the same card as React, SwiftUI and PDF renders, fanned. The reveal breaks the pattern by laying every ghost of the whole deck side by side in time order across one page, labeled by activity-log line, so the reader sees the deck being made. Before reading, the reader sees faint echoes behind firm shapes and senses motion in a still PDF.
