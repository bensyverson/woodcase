## Traps hit today

- **zsh does not word-split `$VAR`**: `for p in "a b"; do set -- $p` and `cmd $FILES` pass one argument. Use `${=VAR}` or explicit calls.
- **Core Image fails silently inside the Bash sandbox** — blur disappears with exit 0; render sandbox-off (leaf `5D9EuW` files the gotcha).
- `FileManager.default.temporaryDirectory` ignores `$TMPDIR` on macOS; use `ScratchDirectory` (gotcha filed).
- MAE is a smoke test: a wrong banking render scored 4.68 against a threshold of 40. Pair MAE with explicit geometric assertions.
